# Assessment scope

Recovery includes a faithful behavioral reconstruction of the stated Phase 1–3
contracts, new verification, a runnable Phase 4 campaign driver, documentation,
an assessment demo notebook and delivery to a review branch.

The required real-data gate is independent from synthetic unit/integration
verification. Only completed real-data campaign runs can support experimental
conclusions. Notebook toy examples and old smoke numbers are not substitutes.

The final technical assessment report remains outside the authorized Phase 4
deliverable. CUDA behavior is unverified on the current CPU-only machine.
